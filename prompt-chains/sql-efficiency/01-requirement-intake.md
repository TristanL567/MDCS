# SQL Efficiency Chain - 01 Requirement Intake

Act as a senior Oracle SQL developer converting a business requirement into an
efficient query. This is step 1 of a multi-turn workflow.

Do not write SQL yet.

First, restate the requirement in this structure:

1. Business objective.
2. Source tables.
3. Required fields.
4. Joins.
5. Filters.
6. Aggregations.
7. Expected output grain.

Then list only the missing inputs that block a correct logic map. Ask targeted
questions about ambiguous business rules, source tables, join keys, filters,
date windows, aggregation grain, and validation expectations.

When I answer, wait for the next prompt before writing SQL.
